# Intentional 1.0 limitations

ForgeCMS 1.0 is a defined scope. These are deliberate boundaries — each is stated so you can plan around it — not unfinished work hidden in the docs. A boundary can move in a future minor release
if it is made a feature with its own spec; until then, treat it as the contract.

| Area                 | Boundary                                                                                                                                                                                                             | What to do instead                                                                                                            |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| API style            | REST only. No GraphQL.                                                                                                                                                                                               | Use the REST API or call the Local API from server code                                                                       |
| Authoring            | No visual page builder, no drag-and-drop schema editing. `blocks` fields are the content primitive.                                                                                                                  | Model pages as `blocks` and render them in your app                                                                           |
| Extensibility        | No plugin system or marketplace. Hooks, access functions and adapters are the extension points.                                                                                                                      | Write hooks; write an adapter that passes the contract suites                                                                 |
| Tooling              | No CLI is required or provided; everything is code and package scripts.                                                                                                                                              | Use package scripts, `runtime.runMigrations()` from a deploy script                                                           |
| Email                | No email adapter (no password reset, invitations or notifications).                                                                                                                                                  | Integrate your own mailer in hooks or a route                                                                                 |
| Uploads              | No presigned or direct-to-storage uploads; bytes pass through your server. No image processing, thumbnails or variants. No Local API upload helper.                                                                  | Pre-process images; resize in your app or a CDN                                                                               |
| Storage consistency  | No transaction across the database and the object store. Storage intents plus `reconcileStorage()` repair the gap.                                                                                                   | Schedule `reconcileStorage()`; keep buckets private                                                                           |
| Relations            | Population is one level deep (`depth: 1`); relations only at the top level of a collection (not inside `group`/`array`/`blocks`).                                                                                    | Fetch the next level yourself; lift relations to top-level fields                                                             |
| Localization         | Only top-level `text`/`textarea` fields in a collection/global that declares `locales`; no localized relation/upload; no filter/sort on localized fields.                                                            | Store structured localized content as separate locale-keyed documents                                                         |
| Queries              | Composite values (`group`, `array`, `blocks`, `richtext`, `json`) cannot be queried inside.                                                                                                                          | Denormalise into a scalar field                                                                                               |
| Schema evolution     | No down migrations; no automatic rename/retype/backfill. Risky drift is refused; reviewed migrations are forward-only and append-only.                                                                               | Forward-fix with a new migration, or restore a backup                                                                         |
| Backup and recovery  | No atomic database + object-store snapshot, no point-in-time recovery, no maintenance mode (quiesce writes operationally). Forge cannot verify that an operator's external backup is complete before it is supplied. | Quiesce writes, export the database, copy the object keys derived from that snapshot ([BACKUP-RESTORE.md](BACKUP-RESTORE.md)) |
| Sessions             | Tokens are stateless and last 24 hours; logout clears the cookie but cannot revoke a Bearer token someone else holds (a password change invalidates earlier sessions).                                               | Rotate the password; use short-lived scoped API keys for machines                                                             |
| Password hashing     | PBKDF2-HMAC-SHA256 at 100,000 iterations, below current OWASP guidance, to fit Workers' CPU limits; throttle logins in front of it. A versioned hash with rehash-on-login is post-1.0.                               | Pass a `throttle` to the login/signup handlers                                                                                |
| Admin framework      | The admin requires Angular 21 (it inherits `@voltui/components` 1.x). No React/Vue admin.                                                                                                                            | Use `@forge-cms/angular` on Angular 22 with your own UI                                                                       |
| Agent Kit            | `@forge-cms/agent` is **experimental**, development-time, read-only tooling; its tools, resources and skills may change in a 1.x minor. It is not a CLI, a hosted service or a deployment agent.                     |
| Cloudflare Analytics | **Experimental**; may change in any release.                                                                                                                                                                         | Do not build on it without pinning                                                                                            |
| Strata               | Not a Forge dependency and not part of the 1.0 API; Server Components integration is not a 1.0 feature.                                                                                                              | —                                                                                                                             |
| S3 providers         | Garage `v2.4.1` is the only S3 service certified by CI. AWS S3, Backblaze B2, Wasabi and others are configurable only.                                                                                               | Run your own connectivity/upload check on your provider                                                                       |
| Remote Cloudflare    | The isolated staging rehearsal is evidence for the profile, not a universal production guarantee or SLA.                                                                                                             | Run the deployment health checks on your own environment                                                                      |
| Performance          | Budgets are for a fixed fixture, not for your traffic. There is no load or capacity guarantee.                                                                                                                       | Measure your own workload                                                                                                     |

See [MATRICES.md](MATRICES.md) for the per-capability status and [SUPPORT.md](SUPPORT.md) for the compatibility promise.
