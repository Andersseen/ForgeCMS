# ForgeCMS 1.0 candidate public surface

Reviewed in [spec 087](specs/087-admin-reuse-and-1.0-surface-freeze.md) (roadmap 0.11 / U03). This is
the **contract** a 1.0 consumer may rely on. The exact export _names_ are machine-checked: the
committed [`api-baseline/*.json`](../api-baseline/) files are compared with the built packages by
`pnpm check:api`. Names are not signatures — defaults, route shapes and behaviour are recorded here and
pinned by tests. If this document and the code disagree, the code and STATE.md win; fix this file.

Status vocabulary: **stable** (1.0 guarantee), **experimental** (public, outside the guarantee),
**deprecated** (works, no effect or superseded, removed after 1.0).

## Packages

through their entry points.

## Client contract (`@forge-cms/angular`)

| Item                       | Contract                                                                                                                                                                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `provideForgeCms(config?)` | The **single** client transport configuration. All keys optional.                                                                                                                                                                                  |
| `baseUrl`                  | Content API base. Default `/api/v1`. Relative or absolute; trailing slash ignored.                                                                                                                                                                 |
| `authBaseUrl`              | Auth API base (`/login`, `/signup`, `/logout`, `/me`, `/users*`). Default `/api/auth`.                                                                                                                                                             |
| `credentials`              | `'include'` (default; cookie session) or `'omit'`. Other origins never get cookies.                                                                                                                                                                |
| `trustedOrigins`           | Extra absolute origins allowed to receive cookies/Bearer. Default none.                                                                                                                                                                            |
| `authToken`, `transport`   | Optional Bearer token / replacement `fetch` transport (must not retry).                                                                                                                                                                            |
| `forgeAuthGuard(options?)` | `CanActivateFn`. `roles?` (default: any authenticated user), `signInPath` (default `/admin/login`), `forbiddenPath` (default `/admin`). Anonymous → `signInPath?returnUrl=<state.url>`; wrong role → `forbiddenPath`. UX only; the server decides. |
| `ForgeAuthSession`         | Root signal service: `user`, `status`, `authenticated`, `loading`, `error`, `expired`; `login/signup/logout/refresh`. A `401` on any request while authenticated → anonymous + `expired`.                                                          |

The admin package contains **no** API URL: where the APIs live is only ever `provideForgeCms()`. A
route-level `provideForgeCms(...)` replaces (does not merge with) the app-level one — repeat the bases.

## Admin integration contract (`@forge-cms/admin`)

### Route helpers

| Helper                                   | Contract                                                                                                                                                              |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `forgeAdminContentRoutes(): Routes`      | Relative: `collections`, `collections/:collection` with children `new` and `:id`. No options. The editor routes carry `canDeactivate`.                                |
| `forgeAdminAuthRoutes(options?): Routes` | Relative: `login`, plus `signup` only when `signup: true` (default `false`). `basePath?` (default `/admin`) is the mount root passed to both pages; invalid → throws. |
| `forgeAdminAnalyticsRoutes()`            | **Experimental.** Relative `analytics`.                                                                                                                               |

Both stable helpers return plain Angular `Routes`; nest them under whatever path the host chooses.
Components read route `data`, so the host must use `provideRouter(..., withComponentInputBinding())`.

### Mount root (`basePath`)

- Default `/admin`. A same-app absolute path with optional nested segments: `/studio`, `/ops/cms`.
  A trailing slash is ignored. Rejected (default used, or an error from `forgeAdminAuthRoutes`): not
  absolute, `//…`, a URL, `..`/`.`/empty segments, `?`, `#`, `\`, whitespace/control characters, bare `/`.
- A path is "under" the root only if it equals it or continues after a `/`: `/studio-evil` is not under
  `/studio`.
- Set the same value in `ForgeAdminConfig.basePath` (layout), `forgeAdminAuthRoutes({ basePath })`
  (pages) and the guard's `signInPath`/`forbiddenPath`. These are one concept spelled in the three
  places that need it; there is no admin provider.
- Everything not derived from `basePath` is the host's: a `nav` is used as written, and the layout's
  **Exit** link always goes to `/`.

### Auth pages

| Behaviour      | Contract                                                                                                                                                                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sign-in path   | `{basePath}/login`                                                                                                                                                                                                                                      |
| Sign-up        | Absent unless `signup: true`; its link is `../signup`; lands at `redirectTo` or `{basePath}`                                                                                                                                                            |
| Sign-in return | `?returnUrl=` honoured only when under `basePath` (path, query and hash kept); else `redirectTo` if under `basePath`; else `basePath`. External, `//`, `javascript:`, backslash, control-character, other-mount and sibling-prefix targets are refused. |
| Logout         | Layout "Log out" → `ForgeAdminConfig.signInPath`, default `{basePath}/login`                                                                                                                                                                            |

### `ForgeAdminConfig`

| Key           | Default            | Runtime effect                                                                                  | Status     |
| ------------- | ------------------ | ----------------------------------------------------------------------------------------------- | ---------- |
| `title`       | `ForgeCMS`         | Sidebar heading                                                                                 | stable     |
| `basePath`    | `/admin`           | Mount root: breadcrumbs, default nav, default sign-in path                                      | stable     |
| `nav`         | built-in nav       | Sidebar groups (`label?`, items `label`/`routerLink`/`icon?`/`exact?`/`adminOnly?`)             | stable     |
| `collections` | all                | Slugs (`{ slug }`; a `CollectionDefinition` also fits) shown on the collections index, in order | stable     |
| `signInPath`  | `{basePath}/login` | Layout "Log in" link and post-logout destination                                                | stable     |
| `logo`        | —                  | none                                                                                            | deprecated |
| `features`    | —                  | none                                                                                            | deprecated |

Configuration is supplied as the layout route's `data.config` (or the `config` input). The collections
index also reads the nearest ancestor `data.config`, so it is set once. `adminOnly` hides an item from
every role except `admin`.

### Navigation

`DEFAULT_ADMIN_NAV` (mount `/admin`) is exactly: **Content → Collections** (`/admin/collections`,
package route `forgeAdminContentRoutes()`) and **Users & Access → Users** (`/admin/users`, admin only;
the host mounts `ForgeUsersWorkspaceComponent` there). A different mount derives the same two links from
`basePath`. Dashboard, media, API and settings pages are not package features and are not in the default;
a host that has them lists them in `nav`. Icons: `dashboard`, `collections`, `media`, `users`, `api`,
`settings`, `analytics`.

### Components intended for direct composition

Stable: `ForgeAdminLayoutComponent`, `ForgeSignInComponent`, `ForgeSignUpComponent`,
`ForgeUsersWorkspaceComponent`, `ForgeCollectionsIndexComponent`, `ForgeCollectionWorkspaceComponent`,
`ForgeDocumentEditorComponent` (+ `canDeactivateForgeDocumentEditor`, async `canDeactivate()`),
`ForgeCollectionListComponent`, `ForgeCollectionFormComponent`, `ForgeFieldControlComponent`,
`ForgeConfirmDialogComponent`, the three pickers, and the state components. All inputs added in
0.12 (`submitting`, `submitDisabled`, `pending`, `pendingLabel`, `error`, `pendingIds`, `label`,
`idPrefix`, `basePath`) are optional; omitting them keeps earlier behaviour.

## Migration notes (0.x → this surface)

- **0.12.0 → 0.12.1 (U01/U02).** `@angular/cdk ^21.2.0` is a direct admin peer.
  `ForgeDocumentEditorComponent.canDeactivate()` may return `Promise<boolean>`: `await` it. New optional
  inputs (see above). `defineField.date({ withTime: true })` now reaches field metadata (runtime,
  angular). Saves are single-shot and a failed save keeps the form; `window.confirm` is gone.
- **U03 (spec 087).**
  - `DEFAULT_ADMIN_NAV` shrank to Collections + admin-only Users. A host that relied on the old
    Dashboard/Media/API/Settings defaults must list them in `nav` (the `apps/www` admin now does).
  - Custom mounts: add `basePath` to `ForgeAdminConfig` and `forgeAdminAuthRoutes()`, and
    `signInPath`/`forbiddenPath` to the guard. `/admin` hosts change nothing.
  - `ForgeAdminConfig.collections` now takes `ReadonlyArray<{ slug }>` (a `CollectionDefinition[]` still
    type-checks as a variable; an inline object literal with extra keys no longer does). Pass slugs;
    do not import server schema into the browser.
  - `logo` and `features` are deprecated no-ops.
  - Route-data config now reaches the collections index (previously only the layout saw it).

## Freeze policy

After spec 087 and until the 1.0 RC, do **not** casually add public exports, route helpers, config
keys, admin field widgets, default routes, peer ranges or persistence providers. Allowed: release
blockers, security fixes, compatibility fixes, documentation corrections, and certification/test
infrastructure. Any public-surface change after this point must, in the same PR, update the API
baseline (`pnpm check:api:update` after review), this inventory, the migration notes, and carry an
honest semver classification (a breaking change is never a patch). Changing a default listed under
"Final defaults" is a release-blocking contract change.
