# Notes for 2.0 (breaking or default-changing work deferred from 1.x)

Items found during 1.x work that cannot ship in a 1.x minor without breaking the stable surface or changing a documented default ([SUPPORT.md](../../SUPPORT.md)). Each names the spec that found it.

| Item                                                                    | Why it is not 1.x                                                                                                                                                                                             | Found in |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Per-session revocation (sign out one device), a list of active sessions | Needs a stored per-session record checked on every request (a new table and a token claim every adapter must honour) and a changed `AuthAdapter` contract; today's revocation is per user (`_sessionVersion`) | spec 107 |
| A session lifetime shorter than 24 h, or sliding/refresh sessions       | Changes a documented default (`SESSION_TTL_SECONDS`) and the client's re-authentication behaviour                                                                                                             | spec 107 |
| A stronger default password work factor                                 | Changes a documented default; on the Cloudflare Workers Free plan it no longer fits 10 ms CPU per login. 1.1 makes it configurable (`PASSWORD_HASHING_PRESETS`)                                               | spec 105 |
| Throttling on by default for login/signup                               | Changes documented handler behaviour; 1.1 ships opt-in certified throttles                                                                                                                                    | spec 106 |
