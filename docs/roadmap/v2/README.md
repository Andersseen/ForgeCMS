# ForgeCMS 2.0 roadmap

ForgeCMS 1.0.0 is the shipped foundation: a code-first, TypeScript-native headless CMS with Angular and Analog integration, a reusable Angular admin, REST and Local APIs, and two certified durable profiles. The V2 roadmap describes the next product direction; it does not change what 1.0 provides or promise delivery dates.

V2 aims to make ForgeCMS production-ready for more teams and editorial work: easier onboarding, a stronger default admin, richer authoring, practical workflows, safer operations, and better developer diagnostics. TypeScript schemas remain the source of truth. Angular and Analog remain the primary integration advantage, while REST and server-side use remain available outside Angular. ForgeCMS remains Cloudflare-first and portable, with a professional reusable admin included by default.
